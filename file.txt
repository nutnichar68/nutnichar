สูตรคำนวณการจ่ายเงินและภาษี
================================

1. สูตรยอดจ่ายก่อนหัก

รายได้รวม = เงินเดือน + ค่าจ้าง + ค่าล่วงเวลา + ค่าคอมมิชชัน + โบนัส + รายได้อื่น

2. สูตรภาษีเงินได้โดยประมาณ

รายได้ทั้งปี = รายได้รวมต่อเดือน x 12

ค่าใช้จ่ายเงินเดือน = MIN(รายได้ทั้งปี x 50%, 100,000)

เงินได้สุทธิเพื่อคำนวณภาษี =
    รายได้ทั้งปี
    - ค่าใช้จ่าย
    - ค่าลดหย่อนส่วนตัว 60,000
    - เงินสมทบประกันสังคมที่จ่ายจริง (ไม่เกิน 9,000 ต่อปี)
    - ค่าลดหย่อนอื่น ๆ ที่มีสิทธิ์

ภาษีทั้งปี = คำนวณตามอัตราภาษีขั้นบันไดด้านล่าง

อัตราภาษีขั้นบันได (ใช้เป็นตัวอย่างสำหรับการประเมิน)
- เงินได้สุทธิ 0 - 150,000 บาท: 0%
- ส่วนที่เกิน 150,000 ถึง 300,000 บาท: 5%
- ส่วนที่เกิน 300,000 ถึง 500,000 บาท: 10%
- ส่วนที่เกิน 500,000 ถึง 750,000 บาท: 15%
- ส่วนที่เกิน 750,000 ถึง 1,000,000 บาท: 20%
- ส่วนที่เกิน 1,000,000 ถึง 2,000,000 บาท: 25%
- ส่วนที่เกิน 2,000,000 ถึง 5,000,000 บาท: 30%
- ส่วนที่เกิน 5,000,000 บาท: 35%

วิธีคิดแบบแยกขั้น:

ภาษีทั้งปี =
  MAX(MIN(เงินได้สุทธิ, 300,000) - 150,000, 0) x 5%
+ MAX(MIN(เงินได้สุทธิ, 500,000) - 300,000, 0) x 10%
+ MAX(MIN(เงินได้สุทธิ, 750,000) - 500,000, 0) x 15%
+ MAX(MIN(เงินได้สุทธิ, 1,000,000) - 750,000, 0) x 20%
+ MAX(MIN(เงินได้สุทธิ, 2,000,000) - 1,000,000, 0) x 25%
+ MAX(MIN(เงินได้สุทธิ, 5,000,000) - 2,000,000, 0) x 30%
+ MAX(เงินได้สุทธิ - 5,000,000, 0) x 35%

ภาษีหักต่อเดือนโดยประมาณ = ภาษีทั้งปี / 12

3. สูตรยอดจ่ายสุทธิ

ยอดจ่ายสุทธิ = รายได้รวมต่อเดือน
              - เงินสมทบประกันสังคม
              - ภาษีหัก ณ ที่จ่ายต่อเดือน
              - เงินหักอื่น ๆ

4. ตัวอย่างคำนวณ

สมมติว่า:
- เงินเดือน 30,000 บาทต่อเดือน
- ไม่มีค่าล่วงเวลา โบนัส หรือรายได้อื่น
- ประกันสังคม 750 บาทต่อเดือน
- ไม่มีค่าลดหย่อนอื่น

รายได้ทั้งปี = 30,000 x 12 = 360,000 บาท
ค่าใช้จ่าย = MIN(360,000 x 50%, 100,000) = 100,000 บาท
ประกันสังคมทั้งปี = 750 x 12 = 9,000 บาท

เงินได้สุทธิ = 360,000 - 100,000 - 60,000 - 9,000
             = 191,000 บาท

ภาษีทั้งปี = (191,000 - 150,000) x 5%
           = 2,050 บาท

ภาษีหักต่อเดือนโดยประมาณ = 2,050 / 12 = 170.83 บาท

ยอดจ่ายสุทธิรายเดือน = 30,000 - 750 - 170.83
                     = 29,079.17 บาท

หมายเหตุ
- สูตรนี้เป็นการประเมินเบื้องต้น ควรตรวจสอบอัตราและค่าลดหย่อนล่าสุดกับกรมสรรพากรหรือผู้จัดทำเงินเดือน
- หากมีโบนัสหรือรายได้ไม่สม่ำเสมอ ควรรวมรายได้ทั้งปีใหม่ก่อนคำนวณภาษี
- การหักภาษี ณ ที่จ่ายจริงอาจแตกต่างจากการนำภาษีทั้งปีหาร 12 เพราะนายจ้างอาจคำนวณตามรายได้สะสมและจำนวนเดือนที่เหลือ
